# MiMo 语音克隆 · 独立小工具

给一段**参考音频** + 一句**文字**，用小米 MiMo 的 `mimo-v2.5-tts-voiceclone` 模型克隆出这个音色的语音。
零依赖（只用 Node 自带模块），双击启动，界面在浏览器里。

## 三步用起来

1. 双击 **`启动.bat`** → 会弹出一个黑色窗口（**别关它**），稍等一两秒浏览器自动打开 `http://127.0.0.1:8391`
2. 在「设置」里填 **MiMo API Key**（官方地址默认已填好）→ 保存
3. 在「参考音频」里选文件（或直接拖进去）→ 在「合成」里写文字 → 点**开始合成**

合成结果会**自动播放**，同时存进 `output\`，页面上也能下载。参考音频会复制到 `refs\`。

> 浏览器没自动弹出来？手动访问 `http://127.0.0.1:8391` 即可（地址是固定的）。

## 怎么控制语气（官方两套，实测都作用于克隆模型）

MiMo 的 TTS 没有 speed / pitch / emotion 这种参数，语气靠**两条指令通道**控制。两套可以叠加用。

### 方法一：自然语言指令（填「语气 / 风格指令」框）

内容会作为 `role: user` 的消息发出去，**只影响语气，不会被念出来**。一句话就够，也可以写得更细（官方叫"导演模式"：角色 / 场景 / 指导三段）。

```
用轻快上扬的语调向领导报喜，语速稍快，带着查到成绩后压抑不住的激动与小骄傲，声音明亮有活力。
```
```
角色：一只住在服务器里的小鲸鱼，性子活泼爱吐槽，说话像群里的熟人，不是客服。
场景：深夜的群里只剩几个人在聊天，有人刚讲了个冷笑话，你想接一句但又要装得不太在意。
指导：语速中等偏快、节奏跳跃，句尾轻轻上扬带笑；气息放松、靠前贴耳、不拖长腔；
      情绪是"想笑又憋着"的得意，偶尔突然收小声音像怕被听见。
```

**实测（同一句话，只改这句指令）**：不加指令 26KB → 加"慵懒·极慢·有气无力"变成 **104KB（+298%）**，明显听得出来慢下来、拖长了。

### 方法二：音频标签（直接写进「要念的文字」里）

- **开头**放整体风格：`(风格1 风格2)要念的内容`——半角 `()`、全角 `（）`、`[]` 都认。
- **句中任意位置**插细粒度标签：`[标签]`。

```
(俏皮)今天天气不错，[轻笑]我们出去走走吧。[长叹一口气]
```

**实测**：`(兴奋 语速加快)` 让同一句话从 26KB 变成 19KB（−26%，明显更快）；句中 `[轻笑]`/`[长叹一口气]` 也能听出效果。

**常用风格**（官方列表节选，不在列表里的自定义风格也认）

| 类别 | 可用值 |
|---|---|
| 基础情绪 | 开心 / 悲伤 / 愤怒 / 恐惧 / 惊讶 / 兴奋 / 委屈 / 平静 / 冷漠 |
| 复合情绪 | 怅然 / 欣慰 / 无奈 / 愧疚 / 释然 / 嫉妒 / 厌倦 / 忐忑 / 动情 |

| 音色定位 | 磁性 / 醇厚 / 清亮 / 空灵 / 稚嫩 / 苍老 / 甜美 / 沙哑 |

### 方法三（最根本的一条）：参考音频决定"音色基线"

克隆的音色、平均语速、情绪底色都是从样本学来的。所以**换一段样本 = 换一套基线**：
- 想要"平时温柔、偶尔炸毛"：准备两段样本（温柔版 / 炸毛版），按需切换；
- 样本本身是快语速，指令再写"语速极慢"也会被往回拉——**基线和指令方向一致时效果最好**。

### 限制

- ⚠️ **克隆模式不支持唱歌**（`(唱歌)` 只在 `mimo-v2.5-tts` 预置音色下有效）。
- 标签与指令都是"指令遵循"，模型照做但**不是硬参数**：极端要求（比如让样本里低沉的男声变清脆少女）只能改样本，不能靠指令硬掰。
- 一句话里风格不要互相打架（"极慢" + "语速加快"），模型会给出四不像的结果。

## 打不开 / 连接被拒绝怎么办

按顺序看这三条：

1. **黑窗口还在不在**：窗口关了 = 服务停了。端口只在本机开着，窗口一关就断。
2. **看 `startup.log`**：窗口里打印的东西都会镜像到这个文件。里面会写明 Node 版本、端口、Key/参考音频状态，以及任何报错（端口被占用、文件缺失等）。窗口一闪就没时，就靠它定位。
3. **端口被占用**：日志里会写 `端口 8391 已被占用` —— 说明已经有一个实例在跑，关掉那个窗口，或改端口：
   ```
   set PORT=8392 && node server.mjs
   ```

> 启动器 `启动.bat` **刻意只写英文**（纯 ASCII）：UTF-8 的 .bat 里带中文时，cmd.exe 在默认 GBK 码页下会解析错乱、脚本可能中途夭折，表现就是"双击后窗口一闪、浏览器拒绝连接"。所有面向你的中文提示都由 `server.mjs` 打印。

## 参考音频怎么选（最影响效果的一步）

| 要求 | 说明 |
|---|---|
| 时长 | **5~15 秒**最好（太长也没用） |
| 内容 | **只有一个说话人**，无背景音乐、无杂音、无重叠对话 |
| 格式 | **mp3 或 wav**（官方只认这两种；m4a/aac 请先用 ffmpeg 转） |
| 体积 | ≤ **8MB** |

换文件后**下一条就生效**，不用重启。

## 需要知道的几件事

- **慢是正常的**：克隆是冷启动最慢的一步。同一段 7.7 秒样本实测：冷调用 **44~112 秒**，热起来约 **2 秒**。默认超时 180 秒，等得久不代表卡死。
- **目前免费**：MiMo 的 TTS 系列（含克隆）在官方定价页标注「限时免费」。官方随时可能改成收费。
- **Key 存哪里**：只写在本目录的 `config.json`，不会外发到别处；页面上可以「清除」。这个文件等于密码，别把它连同整个文件夹打包发给别人，它也已写进 `.gitignore`（不会被误提交）。
- **只监听本机**：服务绑定 `127.0.0.1`，局域网里别的机器访问不到。
- **端口**：默认 8391。被占用时用 `set PORT=8392 && node server.mjs` 换一个。

## 文件结构

```
mimo语音\
├── 启动.bat          双击启动
├── server.mjs        本地服务（零依赖）
├── public\index.html 界面
├── config.json       你的设置与 Key（首次启动自动生成，apiKey 留空）
├── refs\             参考音频存放处（*不入库*：是私人声音样本）
├── output\           合成结果（*不入库*）
└── README.md
```

> 仓库里**不含**任何密钥、参考音频与合成产物：`config.json`、`startup.log`、`refs\*.mp3`、`output\*.mp3` 都在 `.gitignore` 里。克隆下来第一次启动会自动生成一份 `apiKey` 为空的 `config.json`，填上自己的 Key 即可。

## 常见报错对照

| 报错 | 原因 / 处理 |
|---|---|
| `还没填 MiMo API Key` | 设置里填 Key 后点保存 |
| `参考音频读不到：… ENOENT` | 路径不对；本工具已自动忽略粘贴时带上的引号，若仍报错请用「选择文件」重新选一次 |
| `参考音频既不是 wav 也不是 mp3` | 先用 ffmpeg 转格式：`ffmpeg -i in.m4a -vn -c:a libmp3lame -q:a 2 out.mp3` |
| `参考音频太大（… 上限 8MB）` | 裁短或转 mp3 |
| `HTTP 400 … audio.voice must be a DataURL` | 老版本才会出现；本工具已按 DataURL 传（`data:audio/mpeg;base64,…`） |
| `HTTP 401/403` | Key 不对，或 Key 与「接口地址」不是同一家（套餐/中转的 `tp-` Key 只在套餐地址下有效） |
| `HTTP 404` | 接口地址填错，改回 `https://api.xiaomimimo.com/v1` |
| `HTTP 429` | 调用太频繁或额度用尽 |
| `等满 N 秒没返回` | 冷启动慢，把「超时」调大（最大 600 秒）后重试 |

## 实现要点（都是实测踩出来的）

1. `audio.voice` 必须是 **DataURL**（`data:audio/mpeg;base64,…`）——传裸 base64 会被 400 拒掉（官方文档只写"base64 编码"，与实现不一致）。
2. 要念的文字放在 `role: "assistant"` 的 `messages` 里；`role: "user"` 承载语气指令（不会被念出来）。
3. 语气有两套官方通道：自然语言指令（user）+ 音频标签（写进文本）。克隆模式不支持唱歌。
4. 克隆冷启动慢（实测 2~112 秒），所以默认超时给了 180 秒。
5. 参数被拒时服务端会返回明确的 `param` 字段，本工具原文展示，方便定位。
6. 同样的实现也存在于 QQ Agent 的 `mimo-tts` 技能里（voiceclone 模式），两边共用这套 DataURL / 样本校验 / 引号容错 / 超时地板逻辑。
